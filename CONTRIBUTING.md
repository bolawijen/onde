# Contributing to onde

Thank you for your interest in contributing to `onde`!

`onde` is an open-source project licensed under the [Apache License 2.0](LICENSE.txt).

## How to Contribute

1. **Reporting Bugs**:
   - Check existing issues to see if the issue has already been reported.
   - Provide minimal reproducible code snippets, steps to reproduce, and environment details (OS, Bun version, etc.).

2. **Proposing Enhancements**:
   - Open an issue explaining the proposed change, use case, and rationale before starting large changes.

3. **Submitting Pull Requests**:
   - Fork the repository and create your feature branch.
   - Keep commits focused and provide descriptive commit messages.
   - Run tests to ensure changes do not break existing functionality.
   - Submit a Pull Request against the `main` branch.

## Licensing of Contributions

By submitting contributions to `onde`, you agree that your contributions will be licensed under the project's [Apache License 2.0](LICENSE.txt).
