# Support

## Getting Help with onde

`onde` is an independent open-source fork and is maintained independently by its community contributors. It is **not** supported, sponsored, or endorsed by Microsoft Corp.

### Community Channels

- **Issue Tracker**: Use [GitHub Issues](https://github.com/bolawijen/onde/issues) to report bugs or request features. Please search existing issues before filing a new one.
- **Discussions / Questions**: Ask questions or share ideas via GitHub Discussions (if enabled) or repository issues.

### Upstream TypeScript Questions

If you have general TypeScript language questions not related to `onde`'s compiler/features:
- Consult the official [TypeScript Documentation](https://www.typescriptlang.org/docs/).
- Community resources such as Stack Overflow (`typescript` tag).
